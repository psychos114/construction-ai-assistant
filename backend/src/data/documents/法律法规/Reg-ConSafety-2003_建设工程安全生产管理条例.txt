# 建设工程安全生产管理条例 国务院令第393号

# 类别: 法律法规/安全生产法规
# 发布日期: 2003年11月24日
# 施行日期: 2004年2月1日
# 章节: 共8章71条
# ============================================================

## 施工单位安全责任（第四章）

**资质与制度（第20-21条）**：主要负责人全面负责安全生产；项目负责人须取得相应执业资格。

**安全费用（第22条）**：列入概算的安全费用必须专款专用，不得挪作他用。

**总分包责任（第24条）**：总承包负总责；总承包与分包承担连带责任；分包不服从管理导致事故的承担主要责任。

**专项施工方案（第26条—强制性）**：基坑支护与降水、土方开挖、模板工程、起重吊装、脚手架、拆除爆破等危险性较大工程须编制专项方案，经施工单位技术负责人+总监理工程师签字后实施。深基坑、地下暗挖、高大模板的须组织专家论证审查。

**现场防护（第28-32条）**：危险部位设安全警示标志；办公生活区与作业区须分开；不得在未竣工建筑内设集体宿舍；毗邻建筑和地下管线须专项防护；市区须封闭围挡。

**设备管理（第34-35条）**：起重机械和整体提升脚手架须验收合格方可使用，30日内向主管部门登记。

**教育培训（第36-37条）**：管理人员和作业人员每年至少一次安全培训，考核不合格不得上岗。

**意外伤害保险（第38条）**：须为危险作业人员办理意外伤害保险，保险期自开工至竣工。

## 监理单位安全责任（第14条）

- 审查施工组织设计中的安全技术措施或专项方案是否符合工程建设强制性标准
- 发现安全隐患须要求整改；情况严重的须要求暂停止施工并报告建设单位
- 施工单位拒不整改的，须及时向主管部门报告
- 按法律、法规和强制性标准实施监理，对安全生产承担监理责任

## 涉及"强制性标准"的关键条款

| 主体 | 强制性要求 |
|------|-----------|
| 建设单位(第7条) | 不得提出违反强制性标准的要求 |
| 勘察单位(第12条) | 须按强制性标准进行勘察 |
| 设计单位(第13条) | 须按强制性标准进行设计 |
| 监理单位(第14条) | 审查方案是否符合强制性标准；按强制性标准监理 |
| 作业人员(第33条) | 须遵守强制性标准、规章制度和操作规程 |

## 违法处罚

- 建设单位违反强制性标准要求：罚20万-50万
- 勘察设计单位未按强制性标准：罚10万-30万
- 监理单位未按强制性标准监理：罚10万-30万
- 注册执业人员未执行强制性标准：停止执业3月-1年；重大事故终身不予注册
