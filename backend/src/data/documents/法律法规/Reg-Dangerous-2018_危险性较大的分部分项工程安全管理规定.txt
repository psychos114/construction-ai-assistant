# 危险性较大的分部分项工程安全管理规定 住建部令第37号
# 标准编号: 住建部令第37号（2019年第47号令修订）
# 类别: 法律法规/安全生产法规
# 施行日期: 2018年6月1日
# ============================================================

## 危大工程定义

房屋建筑和市政基础设施工程在施工过程中，容易导致人员群死群伤或者造成重大经济损失的分部分项工程。

## 专项施工方案（第十条—第十三条）

**编制（第十条）**：施工单位应在危大工程施工前组织编制专项施工方案。总承包的由总承包单位编制；分包的由专业分包单位编制。

**审批（第十一条）**：须经施工单位技术负责人审核签字+加盖单位公章，并经总监理工程师审查签字+加盖执业印章。

**专家论证（第十二条）**：超过一定规模的危大工程须组织专家论证。专家须从主管部门专家库中选取，不少于5名，与本工程有利害关系的人员不得参加。

**论证结论（第十三条）**：
| 结论 | 处理 |
|------|------|
| 通过 | 直接实施 |
| 修改后通过 | 修改完善后重新审批 |
| 不通过 | 修改后重新组织专家论证 |

## 现场安全管理（第四章）

- 显著位置公告危大工程名称、施工时间、责任人员
- 方案实施前进行方案交底和安全技术交底，双方+专职安全员签字确认
- 严禁擅自修改专项施工方案
- 项目负责人现场履职，专职安全员现场监督
- 监理单位编制监理实施细则，实施专项巡视检查
- 验收合格后设验收标识牌

## 法律责任

| 主体 | 处罚 |
|------|------|
| 施工单位未编制审核方案 | 暂扣安全生产许可证30日 |
| 未组织专家论证/擅自修改方案 | 罚款1万-3万+暂扣证30日 |
| 监理单位未审查方案/未要求整改 | 依法处罚 |
| 监测单位无资质/异常未报告 | 罚款1万-3万 |
