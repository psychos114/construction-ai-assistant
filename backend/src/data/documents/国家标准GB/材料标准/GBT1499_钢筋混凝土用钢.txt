# 钢筋混凝土用钢 GB/T 1499.1-2017 + GB/T 1499.2-2018
# 标准编号: GB/T 1499.1-2017 / GB/T 1499.2-2018
# 类别: 国家标准/材料标准/钢材与钢筋
# 发布部门: 国家市场监管总局
# ============================================================

## GB/T 1499.1 热轧光圆钢筋

- 牌号：HPB300（屈服强度≥300MPa）
- 抗拉强度≥420MPa，断后伸长率≥25%
- 冷弯试验：180°弯曲，弯心直径=1d，无裂纹
- 公称直径范围：6~22mm

## GB/T 1499.2 热轧带肋钢筋

| 牌号 | 屈服强度 | 抗拉强度 | 伸长率 | 碳当量 |
|------|---------|---------|--------|--------|
| HRB400 | ≥400 MPa | ≥540 MPa | ≥16% | ≤0.54% |
| HRB500 | ≥500 MPa | ≥630 MPa | ≥15% | ≤0.55% |
| HRBF400 | ≥400 MPa | ≥540 MPa | ≥16% | ≤0.54% |
| HRBF500 | ≥500 MPa | ≥630 MPa | ≥15% | ≤0.55% |

注：HRBF为细晶粒热轧钢筋，通过控轧控冷工艺细化晶粒，延性更优。

## 抗震钢筋（带"E"牌号）

抗震设防区框架结构主筋强制采用带"E"抗震钢筋（如HRB400E），须满足：

| 指标 | 要求 |
|------|------|
| 强屈比(抗拉/屈服) | ≥1.25 |
| 超强比(屈服实测值/标准值) | ≤1.30 |
| 断后伸长率 | ≥9% |

## 进场检验

同牌号、同炉罐号、同规格≤60t为一批，逐批进行拉伸与冷弯试验。
