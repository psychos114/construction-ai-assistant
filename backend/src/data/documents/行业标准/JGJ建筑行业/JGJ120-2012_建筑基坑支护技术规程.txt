## 强制性条文（5条）

**3.1.2** 基坑支护必须保证基坑周边建(构)筑物、地下管线、道路的安全和正常使用，并保证主体地下结构的施工空间。

**8.1.3** 当基坑开挖面上方的锚杆、土钉、支撑未达到设计要求时，严禁向下超挖土方。

**8.1.4** 采用锚杆或支撑的支护结构，在未达到设计规定的拆除条件时，严禁拆除锚杆或支撑。

**8.1.5** 基坑周边施工材料、设施或车辆荷载严禁超过设计要求的地面荷载限值。

**8.2.2** 安全等级为一级、二级的支护结构，在基坑开挖过程与支护结构使用期内，必须进行支护结构水平位移监测和基坑开挖影响范围内建(构)筑物、地面的沉降监测。

## 支护结构安全等级

| 等级 | 重要性系数 | 适用条件 |
|------|-----------|---------|
| 一级 | ≥1.1 | 基坑周边环境复杂、深度大 |
| 二级 | ≥1.0 | 一般条件 |
| 三级 | ≥0.9 | 简单条件 |

## 排桩（第4.3节）

| 参数 | 要求 |
|------|------|
| 悬臂式桩径 | ≥600mm |
| 锚拉/支撑式桩径 | ≥400mm |
| 桩中心距 | ≤2倍桩径 |
| 混凝土强度 | ≥C25 |
| 纵向钢筋 | ≥8根，净距≥60mm |
| 保护层 | ≥35mm(水下≥50mm) |
| 桩位偏差 | ≤50mm |
| 垂直度 | ≤0.5% |
| 桩身完整性检测 | ≥总桩数20%，且≥5根 |

## 地下连续墙（第4.5节）

- 墙厚：600/800/1000/1200mm
- 槽段长度：4m~6m
- 混凝土：C30~C40，抗渗≥P6
- 纵向钢筋：≥16mm，净距≥75mm，通长配置≥50%
- 保护层：内侧≥50mm，外侧≥70mm

## 土钉墙（第5章）

- 土钉墙：分层设置的纵横向密布土钉群+喷射混凝土面层+原位土体
- 复合土钉墙（新增）：土钉墙与预应力锚杆、微型桩、旋喷桩、搅拌桩组合
- 2012版引入土钉墙土压力调整系数

## 基坑监测与预警

位移控制值确定原则：
1. 有建筑物时：按不影响正常使用确定，符合GB 50007对地基变形允许值的规定
2. 支护构件同时用作主体结构构件时：不应大于主体结构设计变形限值
3. 无上述情况时：根据地区经验按工程具体条件确定

- 设计使用期限不小于一年
- 综合分项系数≥1.25
