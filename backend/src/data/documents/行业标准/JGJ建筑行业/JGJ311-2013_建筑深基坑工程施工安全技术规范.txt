# 建筑深基坑工程施工安全技术规范 JGJ 311-2013
# 标准编号: JGJ 311-2013
# 类别: 行业标准/JGJ施工技术
# 发布部门: 住房和城乡建设部（公告第174号）
# 施行日期: 2014年4月1日
# 适用范围: 开挖深度≥5m的建筑深基坑工程
# 章节: 共11章
# 强制性条文: 第5.4.5条（已废止）
# ============================================================

## 强制性条文

**5.4.5（已废止）** 基坑工程监测数据达到监测报警值，或出现基坑及周边建(构)筑物、管线失稳破坏特征，应立即停止施工作业，撤离人员，待险情排除后方可恢复施工。

## 施工安全等级（第3.0.1条）

| 等级 | 划分条件 |
|------|---------|
| 一级 | 复杂地质软土区≥2层地下室；深度>15m；周边环境复杂；支护与主体结构结合；设计使用年限>2年；降水深度>6m等 |
| 二级 | 除一级以外的基坑工程 |

## 核心安全要求

- 支护结构达到设计强度前，严禁在设计预计的滑裂面范围内堆载
- 基坑开挖应按"先撑后挖、分层分段、对称均衡"原则
- 降水应控制降水深度和出水含砂量，防止管涌和突涌
- 回灌防止坑外地下水位下降过快引起周边沉降
