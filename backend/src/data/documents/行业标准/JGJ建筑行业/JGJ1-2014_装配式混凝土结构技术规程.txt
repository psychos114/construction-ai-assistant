# 标准编号: JGJ 1-2014
# 类别: 行业标准/JGJ施工技术
# 发布部门: 住房和城乡建设部
# 施行日期: 2014年10月1日
# 替代标准: JGJ 1-91
# 强制性条文: 2条(第6.1.3条/11.1.4条)
# ============================================================

## 强制性条文

**6.1.3** 装配整体式结构构件的抗震设计，应根据设防类别、烈度、结构类型和房屋高度采用不同的抗震等级。

**11.1.4** 预制结构构件采用钢筋套筒灌浆连接时，应在构件生产前进行接头抗拉强度试验，每种规格试件数量不少于3个。

## 设计原则

- 采用预制构件与后浇混凝土结合，通过可靠连接技术达到与现浇混凝土结构等同的整体性、延性、承载力和耐久性
- 遵循"少规格、多组合"原则
- 预制构件混凝土≥C30，预应力预制构件≥C40

## 连接节点设计（第6.5节）

| 连接方式 | 要求 |
|---------|------|
| 套筒灌浆连接（推荐） | 满足JGJ 107 I级接头；剪力墙中保护层≥15mm，柱中≥20mm |
| 浆锚搭接 | 直径>20mm不宜采用；动力荷载构件不应采用 |
| 结合面粗糙面 | 面积≥结合面80%；梁凹凸≥6mm，剪力墙≥6mm |

## 预制楼梯连接（6.5.8）

- 简支连接：一端固定铰，一端滑动铰
- 6/7度区搁置长度≥75mm，8度区≥100mm

## 抗震等级（6.1.3 — 强制性条文）

| 结构类型 | Δu/h限值 |
|---------|---------|
| 装配整体式框架 | 1/550 |
| 装配整体式框架-现浇剪力墙 | 1/800 |
| 装配整体式剪力墙 | 1/1000 |

- 接缝受剪承载力增大系数ηⱼ：一、二级1.2，三、四级1.1
- 剪力墙底部加强部位宜采用现浇混凝土
- 阻尼比：装配结构多遇地震取≤5%
