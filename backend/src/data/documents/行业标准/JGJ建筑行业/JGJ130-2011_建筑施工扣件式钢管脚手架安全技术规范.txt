# 建筑施工扣件式钢管脚手架安全技术规范 JGJ 130-2011
# 标准编号: JGJ 130-2011
# 类别: 行业标准/JGJ施工技术
# 发布部门: 住房和城乡建设部（公告第902号）
# 施行日期: 2011年12月1日
# 主编单位: 中国建筑科学研究院
# 强制性条文: 16条
# ============================================================

## 强制性条文（16条）

3.4.3, 6.2.3, 6.3.3, 6.3.5, 6.4.4, 6.6.3, 6.6.5, 7.4.2, 7.4.5, 8.1.4, 9.0.1, 9.0.4, 9.0.5, 9.0.7, 9.0.13, 9.0.14

**3.4.3**：可调托撑受压承载力设计值不应小于40kN，支托板厚不应小于5mm。

## 主要构造参数

| 参数 | 限值 |
|------|------|
| 立杆纵距 la | ≤2.0m |
| 立杆横距 lb | ≤1.5m |
| 步距 h | ≤2.0m |
| 钢管规格 | φ48.3×3.6mm (Q235) |
| 每根钢管质量 | ≤25kg |

## 连墙件

| 项目 | 要求 |
|------|------|
| 连接方式 | 必须刚性连接，能传递拉力和压力 |
| 竖向间距 | ≤3步(≤6m) |
| 水平间距 | ≤3跨(≤6m) |
| 双排架连墙件轴向力 | 风荷载+3.0kN |
| 直角扣件抗滑 | 8.0kN |

## 剪刀撑

| 项目 | 要求 |
|------|------|
| 设置方式 | 连续设置 |
| 角度 | 45°~60° |
| 容许长细比 | 压杆≤250，拉杆≤350 |

## 构件承载力设计值

| 构件 | 承载力(kN) |
|------|-----------|
| 对接扣件（抗滑） | 3.20 |
| 直角扣件、旋转扣件（抗滑） | 8.00 |
| 底座、可调托撑（受压） | 40.00 |

## 允许搭设高度

按不组合风荷载和组合风荷载两种情况分别计算，取较小值。计算时需验算底层立杆段稳定性。满堂脚手架附加系数：H≤20m取1.155，20m<H≤30m取1.191，30m<H≤36m取1.204。

## 挠度限值

| 构件 | 容许挠度 |
|------|---------|
| 脚手板、水平杆 | l/150与10mm取小值 |
| 悬挑受弯杆件 | l/400 |
| 型钢悬挑梁 | l/250 |
