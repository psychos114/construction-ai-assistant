# 建筑施工高处作业安全技术规范 JGJ 80-2016
# 标准编号: JGJ 80-2016
# 类别: 行业标准/JGJ施工技术
# 发布部门: 住房和城乡建设部（第1205号公告）
# 施行日期: 2016年12月1日
# 替代标准: JGJ 80-91
# 章节: 共8章
# 强制性条文: 5条
# ============================================================

## 强制性条文（5条）

**4.1.1 临边作业**：坠落高度基准面2m及以上进行临边作业时，应在临空一侧设置防护栏杆，并应采用密目式安全立网或工具式栏板封闭。

**4.2.1 洞口作业**：洞口短边<500mm封堵；≥500mm设≥1.2m防护栏杆+密目网+挡脚板。非竖向洞口：25-500mm盖板覆盖；500-1500mm盖板或栏杆；≥1500mm设防护栏杆+安全平网。

**5.2.3 悬空作业**：严禁在未固定、无防护设施的构件及管道上进行作业或通行。

**6.4.1 悬挑式操作平台**：搁置点/拉结点/支撑点应设在稳定主体结构上，严禁设在临时设施上。

**8.1.2 安全网**：采用平网防护时，严禁使用密目式安全立网代替平网使用。

## 临边作业（第4.1节）

- 坠落高度≥2m触发防护
- 建筑物外围：有外脚手架时密目网设在立杆上；无脚手架时设防护栏杆+全封闭
- 停层平台两侧：防护栏杆+挡脚板+密目网

## 洞口作业（第4.2节）

| 洞口类型 | 尺寸 | 措施 |
|---------|------|------|
| 竖向洞口 | <500mm | 封堵 |
| 竖向洞口 | ≥500mm | ≥1.2m栏杆+密目网+挡脚板 |
| 非竖向洞口 | 25-500mm | 承载力盖板覆盖 |
| 非竖向洞口 | ≥1500mm | ≥1.2m栏杆+安全平网 |
| 电梯井口 | — | 防护门≥1.5m，井内每10m加安全网 |

## 防护栏杆构造（第4.3节）

- 上杆高1.2m，下杆居中，立杆间距≤2m，挡脚板≥180mm
- 承载力：任意方向最小1kN

## 安全网（第8章）

- 密目式安全立网：10cm×10cm面积≥2000目
- 严禁以密目立网代替平网
- 平网边绳断裂张力≥7kN，系绳间距≤750mm
