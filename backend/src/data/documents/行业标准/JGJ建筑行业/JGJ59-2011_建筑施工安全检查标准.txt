# 建筑施工安全检查标准 JGJ 59-2011
# 标准编号: JGJ59-2011
# 类别: 行业标准/JGJ施工技术
# 发布部门: 住房和城乡建设部（公告第1204号）
# 发布日期: 2011年12月7日
# 施行日期: 2012年7月1日
# 替代标准: JGJ 59-99
# 章节: 共5章+附录
# ============================================================

## 第一章 总则

1.0.1 为科学评价建筑施工现场安全生产，预防生产安全事故的发生，保障施工人员的安全和健康，提高施工管理水平，实现安全检查工作的标准化，制定本标准。

1.0.2 本标准适用于房屋建筑工程施工现场安全生产的检查评定。

1.0.3 建筑施工安全检查除应符合本标准外，尚应符合国家现行有关标准的规定。

## 第二章 术语

2.0.1 保证项目 Assuring items：检查评定项目中，对施工人员生命、设备设施及环境安全起关键性作用的项目。

2.0.2 一般项目 General items：检查评定项目中，除保证项目以外的其他项目。

2.0.3 公示标牌 Public signs：在施工现场的进出口处设置的工程概况牌、管理人员名单及监督电话牌、消防保卫牌、安全生产牌、文明施工牌及施工现场总平面图等。

2.0.4 临边 Temporary edges：施工现场内无围护设施或围护设施高度低于0.8m的楼层周边、楼梯侧边、平台或阳台边、屋面周边和沟、坑、槽、深基础周边等危及人身安全的边沿的简称。

## 第三章 检查评定项目

### 3.1 安全管理

**保证项目**（6项）：
1. 安全生产责任制：工程项目部应建立以项目经理为第一责任人的各级管理人员安全生产责任制；配备专职安全员；实行安全生产目标管理
2. 施工组织设计及专项施工方案：危险性较大的分部分项工程（基坑支护、土方开挖、模板工程、起重吊装、脚手架、拆除爆破等）须编制专项方案；超过一定规模的须经专家论证
3. 安全技术交底：分部分项工程施工前须进行书面安全技术交底，双方签字确认
4. 安全检查：建立定期安全检查制度；隐患整改须做到定人、定时间、定措施
5. 安全教育：新进场工人须进行三级安全教育（公司、项目部、班组）；变换工种须进行新工种安全培训
6. 应急救援：制定生产安全事故应急救援预案；建立应急救援组织；定期组织演练

**一般项目**（4项）：
1. 分包单位安全管理：资质齐全有效，签订安全生产协议书
2. 持证上岗：特种作业人员（电工、焊工、架子工、起重工等）须持证上岗
3. 生产安全事故处理：事故报告及时准确，按"四不放过"原则处理
4. 安全标志：现场危险部位须设置安全警示标志

### 3.2 文明施工

**保证项目**（6项）：
1. 现场围挡：市区主要路段≥2.5m，一般路段≥1.8m，须连续设置
2. 封闭管理：进出口设大门，建立门卫制度
3. 施工场地：主要道路硬化处理，场内有排水设施，道路通畅
4. 材料管理：分类码放整齐，标识清晰，易燃易爆品分类存放
5. 现场办公与住宿：办公区、生活区与作业区分开设置，符合安全要求
6. 现场防火：按规定配备消防器材，高层建筑设消防水源；30m以上高层每层设消防栓

**一般项目**（4项）：
1. 综合治理：建立治安保卫制度
2. 公示标牌：出入口设置"五牌一图"
3. 生活设施：食堂、厕所、淋浴间符合卫生标准
4. 社区服务：控制噪声、粉尘，夜间施工须办理许可

### 3.3~3.10 脚手架工程

| 编号 | 检查项目 | 重要保证项目 |
|------|---------|-------------|
| 3.3 | 扣件式钢管脚手架 | 施工方案、立杆基础(有排水设施)、架体与结构拉结(连墙件)、杆件间距与剪刀撑 |
| 3.4 | 门式钢管脚手架 | 施工方案、架体基础、架体稳定、杆件锁臂、脚手板、交底与验收 |
| 3.5 | 碗扣式钢管脚手架 | 施工方案、架体基础、架体稳定、杆件锁件、脚手板 |
| 3.6 | 承插型盘扣式钢管脚手架 | 同碗扣式，增加连接盘要求 |
| 3.7 | 满堂脚手架 | 高度超过5m的满堂架须编制专项方案 |
| 3.8 | 悬挑式脚手架 | 悬挑钢梁截面高度≥160mm；锚固段长度≥悬挑段1.25倍 |
| 3.9 | 附着式升降脚手架 | 须有防倾覆、防坠落装置；提升设备须经检验 |
| 3.10 | 高处作业吊篮 | 安全锁有效标定期≤1年；上限位装置灵敏可靠 |

### 3.11 基坑工程

保证项目：
- 施工方案（深度≥3m或地质复杂的须编制专项方案；≥5m须专家论证）
- 基坑支护（按规定进行监测，报警值内控制变形）
- 降排水（做好地表水截排，坑内设排水沟和集水井）
- 基坑开挖（严格按方案施工，分层分段开挖，严禁超挖）
- 坑边荷载（基坑边1m内不得堆载，1m外堆载≤设计容许值）
- 安全防护（深度>2m设防护栏杆；设置人员上下专用通道）

### 3.12 模板支架

保证项目：
- 施工方案（高大模板支撑系统须编制专项方案，搭设高度≥8m或跨度≥18m须专家论证）
- 支架基础（地基应承载设计要求，设排水设施）
- 支架构造（立杆间距、水平杆步距符合方案要求；设置扫地杆和剪刀撑）
- 支架稳定（与建筑结构可靠连接；高度超过4m的模板支架须设水平剪刀撑）
- 施工荷载（不得超载堆料）
- 交底与验收

### 3.13 高处作业

安全检查要点：
- **安全帽**：进入现场必须佩戴，质量符合国标（GB 2811）
- **安全网**：密目式安全立网封闭，质量符合国标（GB 5725）
- **安全带**：2m以上高处作业须系挂，高挂低用
- **临边防护**：基坑边、楼层边、阳台边、屋面边设置≥1.2m防护栏杆
- **洞口防护**：≤0.5m的洞口须盖板固定；0.5~1.5m须钢筋网；≥1.5m须加栏杆和安全网
- **通道口防护**：建筑出入口须设双层防护棚（间距≥600mm）
- **攀登作业**：梯子不得垫高使用，上部夹角35°~45°
- **悬空作业**：须设操作平台或张挂安全网
- **移动式操作平台**：面积≤10㎡，高度≤5m
- **悬挑式钢平台**：主梁须用型钢，搁置点须在结构上

### 3.14 施工用电

**必须采用TN-S三相五线制系统（三级配电、二级漏电保护）**

保证项目：
- 外电防护：外电线路安全距离不达标须设绝缘隔离
- 接地与接零：工作接地电阻≤4Ω，重复接地电阻≤10Ω；PE线不得装设开关或熔断器
- 配电线路：电缆须架空或埋地敷设，严禁沿地面明设
- 配电箱与开关箱：执行"三级配电（总配电箱→分配电箱→开关箱）、两级保护"；开关箱与用电设备距离≤3m

一般项目：
- 配电室：耐火等级≥三级；保持通风干燥
- 现场照明：地下室、高温、潮湿等场所须使用安全电压（≤36V）
- 用电档案：绘制用电平面图；接地电阻复测每月一次

### 3.15~3.18 施工机械

| 编号 | 检查项目 | 关键安全要求 |
|------|---------|-------------|
| 3.15 | 物料提升机 | 须设断绳保护装置、安全停靠装置；提升高度≥30m须设重量限制器 |
| 3.16 | 施工升降机 | 限速器每年标定一次；防坠安全器使用期≤5年；每3个月做一次坠落试验 |
| 3.17 | 塔式起重机 | 力矩限制器、起重量限制器、高度限位器、变幅限位器、回转限位器须灵敏有效 |
| 3.18 | 起重吊装 | 作业区设警戒线；多台起重机作业须有防碰撞措施；六级以上大风停止吊装 |
| 3.19 | 施工机具 | 圆盘锯、手持电动工具、钢筋机械、电焊机、搅拌机、气瓶等须有防护装置 |

## 第四章 检查评分方法

**4.0.1（强制性条文）** 建筑施工安全检查评定中，保证项目应全数检查。

- 各分项检查评分表满分100分
- 采用扣减分值方法，单次扣分值不超应得分值
- 按汇总表计算总得分

## 第五章 检查评定等级

**5.0.3（强制性条文）** 当建筑施工安全检查评定的等级为不合格时，必须限期整改达到合格。

| 等级 | 评定标准 |
|------|---------|
| **优良** | 分项检查评分表无零分，且汇总表得分≥80分 |
| **合格** | 分项检查评分表无零分，且汇总表得分≥70分 |
| **不合格** | 汇总表得分<70分，或任一分项检查评分表得零分 |
